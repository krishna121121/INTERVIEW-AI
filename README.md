# 📖 Overview

AI Interview Preparation Platform is an intelligent web application that helps job seekers prepare for interviews by analyzing their resume, job description, and profile.

Instead of searching random interview questions online, the platform generates personalized interview preparation material based on the exact role you are applying for.

---

# ✨ Features

### 🔐 Authentication

- User Registration
- User Login
- JWT Authentication
- Secure Protected Routes

---

### 📄 Resume Analysis

- Upload Resume (PDF/DOCX)
- Extract Resume Content
- AI Resume Understanding

---

### 💼 Job Description Matching

- Paste Job Description
- AI compares Resume with JD
- Calculates Match Score

---

### 🤖 AI Generated Interview Report

Each report contains:

✅ Match Score

✅ Technical Interview Questions

✅ Behavioral Interview Questions

✅ Model Answers

✅ Question Intentions

✅ Personalized Preparation Roadmap

---

### 📚 Previous Reports

- View all previous interview reports
- Open any previous report
- Stored permanently in MongoDB

---

### 🎯 Personalized Learning

AI creates a custom roadmap including:

- Topics to Study
- Daily Plan
- Missing Skills
- Weak Areas
- Preparation Timeline

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/AI-Interview-Preparation.git
```

```bash
cd AI-Interview-Preparation
```

---

## Install Frontend

```bash
cd client

npm install
```

---

## Install Backend

```bash
cd server

npm install
```

---

## Environment Variables

Create a `.env` file

```env
PORT=3000

MONGO_URI=Your MongoDB URI

JWT_SECRET=Your Secret

GEMINI_API_KEY=Your Gemini API Key
```

---

## Start Backend

```bash
npm run dev
```

---

## Start Frontend

```bash
npm run dev
```

# 🌟 Why this Project?

Finding relevant interview questions for every company and job role is time-consuming.

This platform automatically analyzes your profile and generates personalized interview preparation material using AI, helping candidates focus on what matters most.
